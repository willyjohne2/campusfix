## 📊 How to Rank First in Search Engines

### Step 1: Submit to Search Engines
After deployment, submit your site to:

1. **Google Search Console**
   - Go to: https://search.google.com/search-console
   - Add property: yourdomain.com
   - Submit sitemap: yourdomain.com/sitemap.xml
   - Request indexing for homepage

2. **Bing Webmaster Tools**
   - Go to: https://www.bing.com/webmasters
   - Add site and submit sitemap
   - Verify ownership

3. **Yandex Webmaster**
   - For international reach
   - Submit sitemap

### Step 2: Optimize Content
- Write unique, valuable content about campus issues
- Use keywords naturally:
  - "campus issue reporting"
  - "student facility management"
  - "campus problem reporting system"
  - "[Your University Name] issues"
- Add blog posts about common campus problems
- Include student testimonials

### Step 3: Build Backlinks
- Share on social media (Facebook, Twitter, LinkedIn)
- Partner with university departments
- Get listed on university directory
- Submit to educational resource sites
- Create press release about launch

### Step 4: Local SEO (If Applicable)
- Add university name and location to content
- Register on Google My Business (if applicable)
- Include address and contact info
- Use location-specific keywords

### Step 5: Monitor & Improve
Check weekly:
- Google Search Console → Performance
- Check which keywords drive traffic
- Analyze user behavior
- Improve low-performing pages

## 📝 Remember Me Duration

**Changed from 30 days to 5 days:**
- Users checking "Remember Me" stay logged in for 5 days
- Unchecked = Session expires when browser closes
- More secure for shared/public computers
- Balances convenience and security
